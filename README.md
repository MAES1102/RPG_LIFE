# 🎮 RPG_LIFE — Геймифицированный трекер реальной жизни

Приложение для трекинга реальных достижений (спорт, учеба, привычки), которое выглядит и ощущается как видеоигра (киберпанк-терминал и интерактивная 2D/Rive-сцена с персонажем и базой).

---

## ✨ Ключевые продуктовые принципы
* **Минимум рутины («без задротства»):** Настройка нового квеста занимает **10 секунд** — никаких сложных таблиц и ручных коэффициентов.
* **Создание квестов через ИИ в одну строку:** Игрок вводит желание обычным текстом (например, *«Бегать по 3 км три раза в неделю»*). Бэкенд через `gemini-2.5-flash` (Structured Outputs) сам определяет сферу, сложность и способ автоматического считывания прогресса.
* **Кастомизация без перегруза:**
  * До **4 сфер развития** (базово: 🧠 Мозг, 💪 Тело, ⚡ Энергия, 🎨 Душа — названия и иконки редактируются под себя).
  * Сложность задается **3 простыми кнопками**: `Легко (1.0x)`, `Нормально (1.5x)`, `Хардкор (2.5x)`.
  * Готовые стартовые пресеты (`Студент`, `Спортсмен`, `Кибер-Кочевник`) для мгновенного старта без пустого экрана.
* **Автоматическое считывание успехов:**
  * `health_api` — спорт и активность через **Apple Health / Google Fit**.
  * `timer` — учеба и глубокая работа через встроенный игровой **Рейд-таймер фокуса**.
  * `manual` — разовые задачи в 1 тап или фото-пруф.
* **Здоровая игровая экономика (отказ от «покупки отдыха»):**
  * Золото тратится **только на внутриигровые вещи**: скины/экипировку героя, визуальный апгрейд базы, питомцев-компаньонов и бустеры (например, «Щит заморозки стрика»).
* **Связка «Прогресс в реальной жизни → Боевые статы аватара» (`CombatStats`):**
  * 💪 **Тело (`body`):** `max_hp` (100 + 35 за уровень) и `attack_power` (10 + 5 за уровень).
  * 🧠 **Мозг (`brain`):** `chrono_slow_percent` (замедление времени *Sandevistan* от 10% до 50%) и `parry_window_ms` (расширение окна тайминга).
  * ⚡ **Энергия (`energy`):** `dash_cooldown_sec` (уменьшение перезарядки рывка с неуязвимостью) и `stamina_regen`.
  * 🎨 **Душа (`soul`):** `crit_chance` (шанс критического удара `x2.5`) и `pet_assist_shield` (бонусный щит от питомца-компаньона).
* **Хардкорные мини-игры 60 FPS («Нейро-Арена / Башня Боссов»):**
  * **Режим 1: «Прорыв Фаервола (Bullet-Hell Boss Fight)»** — уклонение от плотных паттернов лазеров/снарядов босса с использованием *Sandevistan* и *Рывка*.
  * **Режим 2: «Кибер-Дуэль (Reflex Parry Strike)»** — скоростная дуэль на реакцию с попаданием в движущиеся тайминг-зоны парирования.
* **Кибер-Камера (Workout HUD) и Шеринг 9:16 (Instagram / Telegram Stories):**
  * Неоновый игровой счетчик повторений (отжимания, приседания, бёрпи) с живым расчетом `+XP` и фото-снапом результата.
  * Генератор карточек **9:16** в стиле Strava и карточки Победы над Боссом с кастомным **Радар-чартом 4 сфер**.

## 📐 Математическая модель прогрессии и баланса

1. **Опыт за действие ($XP_{action}$):**
   $$XP_{action} = \text{round}(100 \times D \times M_{streak} \times M_{overachieve})$$
   * $D$ (сложность): Легко = `1.0`, Нормально = `1.5`, Хардкор = `2.5`.
   * $M_{streak}$ (бонус за стабильность): $+5\%$ за каждый день подряд, максимум $+50\%$ (`1.0`..`1.5`).
   * $M_{overachieve}$ (перевыполнение цели): отношение факта к цели, ограничено сверху `1.5`.
2. **Порог следующего уровня ($XP_{next}$):**
   $$XP_{next} = \text{round}(500 \times Level^{1.4})$$
   *(Первый левел-ап происходит за 500 XP — уже в первый день для удержания).*
3. **Начисление золота:**
   $$Gold = \lfloor XP_{action} \times 0.2 \rfloor$$

## 🚀 Быстрый запуск

### 1. База данных (Supabase)
Выполните в SQL Editor вашего проекта Supabase файлы:
1. `database/schema.sql`
2. `database/seed.sql`

### 2. Бэкенд (FastAPI + Gemini 2.5 Flash)
```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Укажите GEMINI_API_KEY в .env (без ключа автоматически работает локальный парсер-фоллбэк)
uvicorn app.main:app --reload --port 8000
```

Запуск модульных тестов математической модели:
```bash
PYTHONPATH=backend python3 -m unittest backend/tests/test_progression_and_api.py
```

### 3. Мобильный / Десктоп клиент (Flutter)
```bash
cd mobile
flutter pub get
flutter run
```
